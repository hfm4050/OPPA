# 중년 남성 코디 쇼츠 제작기

Windows에서 상품 목록을 읽어 10~20초 세로 쇼츠를 일괄 제작합니다. 한 편에 여성 호스트 한 명이 등장하며, 호스트를 지정하지 않으면 목록 순서대로 A → B → C를 반복합니다. 각 호스트의 얼굴과 의상은 보관된 첫 프레임을, 목소리는 지정된 Gemini TTS 보이스를 재사용합니다.

| 호스트 | 캐릭터 | 외모 설정 | 취미 | 시그니처 룩 |
| --- | --- | --- | --- | --- |
| A 한유나 | 섹시하지만 귀엽고 장난기 있는 진행 | 32세, 168cm, 51kg. 하트형 얼굴, 밝은 눈웃음, 한쪽 보조개, 긴 밤색 웨이브 | 디저트 카페 탐방, 테니스 | 버터 옐로 핏 니트, 슬림 인디고 청바지, 흰색 로우탑 스니커즈 |
| B 서혜원 | 섹시하고 능청스럽게 플러팅하는 진행 | 39세, 170cm, 58kg. 또렷한 눈매, 왼쪽 눈 아래 점, 어깨 길이의 검은 직모 | 향수 수집, 재즈 LP 감상 | 버건디 모크넥, 블랙 스커트 정장, 차콜 스타킹, 블랙 스틸레토 힐 |
| C 윤서하 | 섹시하지만 청순하고 다정한 진행 | 43세, 166cm, 54kg. 부드러운 타원형 얼굴, 한쪽 귀 뒤로 넘긴 턱선 단발 | 필름 사진, 꽃꽂이 | 아이보리 보트넥 니트, 옆트임 네이비 무릎 길이 스커트, 살색 스타킹, 크림 스틸레토 힐 |

호스트는 남성을 ‘오빠’라고 부릅니다. 직접 입력한 대본에 ‘아저씨’가 있으면 영상 자막과 음성 생성 전에 ‘오빠’로 바꿉니다. 기존 `hosts/A.png`·`B.png`·`C.png` 파일이 있으면 `hosts all`은 해당 파일을 재사용합니다.

## 무료 미리보기

브라우저에서 사용하려면 `studio.html`을 더블클릭합니다. 캐릭터 룩북, 길이와 등급 선택, 비용 계산, 15초 샘플과 상품 목록 저장을 한 화면에서 사용할 수 있습니다.

실제 영상을 만들려면 `Open Studio.cmd`를 더블클릭합니다. 자동으로 열린 브라우저에서 상품 정보와 사진을 입력하고 **쇼츠 제작**을 누르면 됩니다. Gemini API 키는 환경 변수에 설정되어 있거나 화면에서 입력할 수 있습니다. 제작이 끝날 때까지 실행 창을 열어 두면 화면에서 완성 MP4를 재생하고 저장할 수 있습니다.

상품 사진은 파일을 선택하거나 상품 사진 칸으로 끌어놓거나, 이미지를 복사한 뒤 화면에서 Ctrl+V로 붙여넣을 수 있습니다. 최대 4장까지 사용할 수 있습니다.

호스트를 선택하고 **캐릭터 룩북 보기**를 누르면 전체 착장 이미지가 카드 아래에 펼쳐집니다. **썸네일 편집**에서는 현재 영상 프레임이나 상품 사진을 배경으로 선택한 뒤 문구, 글꼴, 크기, 색상, 외곽선, 그림자를 조정할 수 있습니다. 문구를 끌어 배치하고 **썸네일 JPG 저장**을 누릅니다. HTML 파일로 직접 열었을 때는 배경 사진을 선택하고, 영상 프레임을 쓰려면 `Open Studio.cmd`로 제작실을 실행합니다.

Windows의 Git이 설치되어 있으면 `Open Studio.cmd` 실행 시 GitHub에서 최신 버전을 확인합니다. 접속이 어려울 때는 저장된 버전을 실행하며, 호스트와 제작 결과는 최초 실행 폴더에 계속 저장합니다.

Python 3.11 이상, PATH에 등록된 FFmpeg 및 FFprobe, FFmpeg의 libass 및 libx264가 필요합니다. PowerShell에서 이 폴더를 연 뒤 실행합니다.

```powershell
$reference = "$env:USERPROFILE/Downloads/gemini_generated_video_10230075.mp4"
python -X utf8 shorts.py build demo.json --preview $reference
```

첨부 영상의 첫 4초와 첨부 영상에서 추출한 착장 컷을 사용합니다. 자막, 화면 전환, 안내 문구를 확인할 수 있는 무음 샘플입니다.

## 실제 제작

1. [Google AI Studio](https://aistudio.google.com/apikey)에서 Veo 사용이 가능한 유료 Gemini API 프로젝트의 키를 준비합니다. 환경 변수 `GEMINI_API_KEY`를 설정하거나 실행 시 입력합니다. 환경 변수를 설정하면 일괄 실행 시에도 같은 키를 사용합니다.
2. 아래 명령으로 A·B·C의 기준 이미지를 한 번 생성합니다. Gemini는 `characters/`의 캐릭터 시트를 참조해 얼굴·헤어와 첫 번째 착장을 담은 9:16 인트로 프레임을 만듭니다. 준비한 9:16 PNG가 있다면 `hosts/A.png`, `hosts/B.png`, `hosts/C.png`에 넣어 사용할 수도 있습니다.
3. 예제 목록을 복사한 뒤 상품명, 확인된 특징, 쿠팡 파트너스에서 발급받은 링크, 사용 권한이 있는 상품 사진을 입력합니다. 이미지 경로는 상품 목록 파일이 있는 폴더를 기준으로 합니다.

```powershell
python -X utf8 shorts.py hosts all
Copy-Item products.example.json products.json
notepad products.json
python -X utf8 shorts.py build products.json --estimate
python -X utf8 shorts.py build products.json
```

상품마다 고유한 영문·숫자 `id`를 지정합니다. `images`에는 PNG·JPG·WebP 1~4장을 넣습니다. 기본 길이는 15초이며 `seconds`는 10~20 사이의 정수입니다. `host`는 A·B·C 중 하나를 지정할 수 있고, `veo`는 `lite`, `fast`, `standard`를 지원합니다. `script`를 생략하면 Gemini가 한국어 대본을 만들고, 직접 작성하려면 `demo.json`처럼 `hook`과 `lines` 3개를 지정합니다.

영상은 **Veo 인트로 4초 → 상품 사진 줌 → 프로필 안내** 순으로 이어집니다. Gemini TTS 음성에 맞춰 한글 자막을 얹고, 합성한 영상은 720×1280, 30fps MP4로 저장합니다. 파일 경로는 실행 결과에 출력됩니다.

## 결과와 쿠팡 링크

- `short.mp4`는 업로드용 영상입니다.
- `captions.srt`는 별도 자막입니다.
- `upload.txt`는 업로드 제목·설명과 제휴 표시 문구, 프로필에 등록할 링크를 담습니다.
- `output/jobs/links.html`은 제작한 상품을 모은 페이지입니다. 이 파일을 HTTPS로 공개 호스팅한 뒤 주소를 YouTube 채널 프로필 링크에 등록하면 됩니다. 상품 하나만 운영한다면 해당 파트너스 링크를 채널 프로필에 직접 등록할 수 있습니다. [YouTube 링크 안내](https://support.google.com/youtube/answer/13748639?hl=ko)

한 번에 여러 상품을 처리하며, 일부 상품이 실패하면 나머지 상품을 계속 처리합니다. 같은 입력으로 재실행하면 저장된 대본, 음성, Veo 작업 ID와 완성 영상을 재사용합니다. 쿠팡 링크 발급, 상품 사진 확보, 링크 페이지 호스팅, 유튜브 게시와 상품 태그 등록은 운영 단계에서 진행합니다.

## 생성비

Veo 720p 인트로 4초가 한 번 성공할 때 Lite **$0.20**, Fast **$0.40**, Standard **$1.60**입니다. 호스트 기준 이미지 생성은 최초 1회, 대본과 TTS는 편마다 별도 과금될 수 있습니다. 2026년 11월 9일 기준 3.8 Flash TTS의 10초 출력은 약 $0.00225이며 텍스트 입력 요금이 추가됩니다. 품질 검수 후 성공 클립을 다시 생성하면 해당 생성비가 더해집니다.
